

## 1. What is Reflection?

Java Reflection is the ability to **examine and modify** the behaviour of Classes, Methods, Fields, and Interfaces **at runtime**.

### What you can do with Reflection:

- Inspect all methods present in a class
- Inspect all fields present in a class
- Get the return type of any method
- Get the modifier of a class/method/field (public, private, etc.)
- Find all interfaces a class has implemented
- Read **and** change the value of public **and** private fields at runtime

> **Key interview point:** Reflection allows runtime introspection — you don't need to know a class at compile time.

## 2. How to Get a `Class` Object (3 Ways)

Before reflecting on anything, you need a `Class` object. Every class loaded by the JVM gets exactly **one** `Class` object (singleton per classloader).

|Method|Syntax|Use when…|
|---|---|---|
|`Class.forName()`|`Class c = Class.forName("Bird");`|You only have the class name as a **String**|
|`.class` literal|`Class c = Bird.class;`|You have the **type** available at compile time|
|`getClass()`|`Class c = birdObj.getClass();`|You have an **instance** of the object|

```java
// Method 1 — forName
Class birdClass = Class.forName("Bird");

// Method 2 — .class
Class birdClass = Bird.class;

// Method 3 — getClass()
Bird birdObj = new Bird();
Class birdClass = birdObj.getClass();
```

## 3. The `java.lang.reflect` Package

The `java.lang.reflect` package provides the classes that represent reflective metadata:

- `Field` — represents a field of a class
- `Method` — represents a method
- `Constructor` — represents a constructor
- `Modifier` — decodes modifier integers (public, private, static, etc.)

> These classes are returned by the `get*` methods on the `Class` object.

## 4. Key Methods on `Class` Object

All methods on `Class` are **getters only** (no setters — use `Field`, `Method`, etc. to mutate).

### Class Identity

|Method|Returns|
|---|---|
|`getName()`|`String`|
|`getSimpleName()`|`String`|
|`getSuperclass()`|`Class`|
|`getInterfaces()`|`Class[]`|
|`getModifiers()`|`int` (decode with `Modifier.toString()`)|
|`getPackage()`|`Package`|

### Fields

|Method|Scope|
|---|---|
|`getFields()`|Public fields only (including inherited)|
|`getDeclaredFields()`|**All fields** declared in this class (public + private)|
|`getDeclaredField(String name)`|Single field by name|

### Methods

|Method|Scope|
|---|---|
|`getMethods()`|Public methods (including inherited)|
|`getDeclaredMethods()`|All methods declared in this class|
|`getDeclaredMethod(String name, Class<?>... paramTypes)`|Single method by name + param types|

### Constructors

|Method|Scope|
|---|---|
|`getConstructors()`|Public constructors|
|`getDeclaredConstructors()`|**All** constructors (including private)|

### Other Useful Methods

|Method|Returns|
|---|---|
|`isInterface()`|`boolean`|
|`isAnnotation()`|`boolean`|
|`getAnnotations()`|`Annotation[]`|
|`getComponentType()`|`Class` (for arrays)|
|`newInstance()`|`Object` (deprecated in Java 9+; use constructor)|

## 5. Reflecting on Fields

### Example Class

```java
public class Eagle {
    public String breed;
    private boolean canSwim;

    public void fly() { System.out.println("fly"); }
    private void eat() { System.out.println("eat"); }
}
```

### Getting Public Fields

```java
Class eagleClass = Eagle.class;
Field[] fields = eagleClass.getFields(); // public only
for (Field f : fields) {
    System.out.println("FieldName: " + f.getName());
    System.out.println("Type: " + f.getType());
    System.out.println("Modifier: " + Modifier.toString(f.getModifiers()));
}
// Output: breed, java.lang.String, public
```

### Getting All Fields (including private)

```java
Field[] fields = eagleClass.getDeclaredFields(); // public + private
// Output includes: canSwim, boolean, private
```

### Key `Field` methods:

|Method|Returns|
|---|---|
|`getName()`|`String`|
|`getType()`|`Class<?>`|
|`getModifiers()`|`int`|
|`get(Object obj)`|`Object`|
|`set(Object obj, Object value)`|`void`|
|`getAnnotation(Class<T>)`|`T`|
|`getBoolean(Object obj)`|`boolean`|
|`getInt(Object obj)`|`int`|
|`getDouble(Object obj)`|`double`|

## 6. Reading & Setting Field Values

### Setting a Public Field

```java
Eagle eagleObj = new Eagle();
Field field = eagleClass.getField("breed");
field.set(eagleObj, "Golden");
System.out.println(field.get(eagleObj)); // Golden
```

### Setting a **Private** Field (bypass access control)

```java
Eagle eagleObj = new Eagle();
Field field = eagleClass.getDeclaredField("canSwim");
field.setAccessible(true);          // ← CRITICAL step
field.set(eagleObj, true);
System.out.println(field.get(eagleObj)); // true
// Output: "value is set to true"
```

> **Interview point:** `setAccessible(true)` bypasses the Java access modifier system. This works even for `private` fields. It can be restricted by the Security Manager.

## 7. Invoking Methods via Reflection

### Example

```java
public class Eagle {
    Eagle() {}
    public void fly(int intParam, boolean boolParam, String strParam) {
        System.out.println("fly intParam: " + intParam + " boolParam: "
            + boolParam + " strParam: " + strParam);
    }
}
```

```java
// In Main — must declare checked exceptions
public static void main(String[] args)
    throws InvocationTargetException, InstantiationException, IllegalAccessException {

    Class eagleClass = Class.forName("Eagle");
    Object eagleObject = eagleClass.newInstance();

    // Get method: name + parameter types
    Method flyMethod = eagleClass.getMethod("fly", int.class, boolean.class, String.class);

    // Invoke: object + argument values
    flyMethod.invoke(eagleObject, 1, true, "hello");
}
// Output: fly intParam: 1 boolParam: true strParam: hello
```

### Key `Method` methods:

|Method|Returns|
|---|---|
|`getName()`|`String`|
|`getModifiers()`|`int`|
|`getReturnType()`|`Class<?>`|
|`getParameterTypes()`|`Class<?>[]`|
|`getParameterCount()`|`int`|
|`getExceptionTypes()`|`Class<?>[]`|
|`invoke(Object obj, Object... args)`|`Object`|
|`setAccessible(boolean)`|`void`|
|`getAnnotations()`|`Annotation[]`|

## 8. Reflection of Constructors

### Accessing a Private Constructor

```java
public class Eagle {
    private Eagle() {} // private constructor
    public void fly() { System.out.println("fly"); }
}
```

```java
public static void main(String[] args)
    throws InvocationTargetException, InstantiationException, IllegalAccessException {

    Class eagleClass = Eagle.class;

    // getDeclaredConstructors() to access private constructors too
    Constructor[] eagleConstructorList = eagleClass.getDeclaredConstructors();

    for (Constructor eagleConstructor : eagleConstructorList) {
        System.out.println("Modifier: " + Modifier.toString(eagleConstructor.getModifiers()));

        eagleConstructor.setAccessible(true);                         // bypass private
        Eagle eagleObject = (Eagle) eagleConstructor.newInstance();   // instantiate
        eagleObject.fly();
    }
}
```

### Key `Constructor` methods:

|Method|Returns|
|---|---|
|`getName()`|`String`|
|`getModifiers()`|`int`|
|`getParameterTypes()`|`Class<?>[]`|
|`getParameterCount()`|`int`|
|`getExceptionTypes()`|`Class<?>[]`|
|`newInstance(Object... args)`|`T`|
|`setAccessible(boolean)`|`void`|
|`getAnnotation(Class<T>)`|`T`|
|`getDeclaredAnnotations()`|`Annotation[]`|
|`getParameters()`|`Parameter[]`|
|`getTypeParameters()`|`TypeVariable<Constructor>[]`|
|`toGenericString()`|`String`|

## 9. Quick-Reference Cheat Sheet

```
Class object → obtained via forName() / .class / getClass()
       │
       ├── getDeclaredFields()      → Field[]       (all, incl. private)
       ├── getDeclaredMethods()     → Method[]      (all, incl. private)
       ├── getDeclaredConstructors()→ Constructor[] (all, incl. private)
       │
       └── For any of the above:
               field.setAccessible(true)   ← bypass private
               field.get(obj)              ← read value
               field.set(obj, value)       ← write value
               method.invoke(obj, args...) ← call method
               ctor.newInstance(args...)   ← create instance
```

## 10. Common Interview Questions

**Q: What is Reflection used for in real life?**

> Frameworks like Spring, Hibernate, JUnit use Reflection heavily — to inject dependencies, map objects to DB columns, discover test methods at runtime.

**Q: Can Reflection access private members?**

> Yes — call `setAccessible(true)` on the `Field`, `Method`, or `Constructor` before accessing it.

**Q: What is the difference between `getFields()` and `getDeclaredFields()`?**

> `getFields()` returns only **public** fields, including inherited ones. `getDeclaredFields()` returns **all fields declared in that class** (public + private + protected + package-private), but NOT inherited fields.

**Q: What exceptions must you handle when using Reflection?**

> `ClassNotFoundException` (forName), `NoSuchFieldException`, `NoSuchMethodException`, `IllegalAccessException`, `InvocationTargetException`, `InstantiationException`.

**Q: What are the downsides of Reflection?**

> - **Performance overhead** — slower than direct calls
> - **Security restrictions** — may be blocked by SecurityManager
> - **Breaks encapsulation** — violates access modifiers
> - **Breaks singleton** - violates access modifiers of private constructer
> - **Harder to maintain** — loses compile-time type checking

**Q: How do you get the `Class` object of a primitive type?**

> Use the `.class` literal: `int.class`, `boolean.class`, etc.

**Q: What is the difference between `getMethod()` and `getDeclaredMethod()`?**

> `getMethod()` searches public methods including inherited. `getDeclaredMethod()` searches all methods declared in the class regardless of modifier, but not inherited.
