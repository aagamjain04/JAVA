## 2. Decision Making Statements

### 1. `if` (Simple If)

If condition is true, the block executes. If false, it is skipped entirely.

```java
if (Boolean condition) {
    // executes only when condition is true
}
```

```java
int val = 15;
if (val > 10) {
    System.out.println("val is greater than 10");  // prints
}
```

---

### 2. `if-else`

If condition is true → `if` block executes. If false → `else` block executes.

```java
int val = 15;
if (val < 10) {
    System.out.println("val is less than 10");
} else {
    System.out.println("val is greater than or equal to 10");  // prints
}
```

---

### 3. `if-else-if` Ladder

Chains multiple `if` statements. Evaluates conditions top to bottom — the first condition that is true gets executed; once one executes, the rest are skipped.

```java
int val = 13;
if (val < 10) {
    System.out.println("val is less than 10");
} else if (val < 15) {
    System.out.println("val is: 13");       // prints
} else if (val < 20) {
    System.out.println("val is less than 20");
} else {
    System.out.println("this code will execute anyhow");
}
// Output: val is: 13
```

---

### 4. Nested `if`

An `if` statement inside another `if` (or `else`) block.

```java
int val = 8;
if (val < 10) {
    if (val < 5) {
        System.out.println("val is less than 5");
    } else {
        System.out.println("val is greater than 5 but less than 10");  // prints
    }
} else {
    System.out.println("this code will execute anyhow");
}
```

---

### 5. Switch Statement

Similar to `if-else-if` ladder — based on the value of an expression, a particular `case` block executes. More readable when comparing a single variable against many constant values.

**Syntax:**

```java
switch (expression) {
    case value_1:
        // break statements
        break;
    case value_2:
        // break statements
        break;
    // ...
    case value_N:
        // break statements
        break;
    default:        // optional — executes if no case matches
        // break statements
}
```

**Example:**

```java
int val = 2;
switch (val) {
    case 1:
        System.out.println("One");
        break;
    case 2:
        System.out.println("Two");   // prints
        break;
    case 3:
        System.out.println("Three");
        break;
    default:
        System.out.println("Default");
}
```

#### Things to watch out for:

**Fall-through (no `break`):** If a `break` is missing, execution falls through to the next case.

```java
int val = 1;
switch (val) {
    case 1:
        System.out.println("One");    // prints
        // no break — falls through!
    case 2:
        System.out.println("Two");    // also prints!
        break;
}
// Output: One
//         Two
```

**Important Switch rules:**

- Two `case` values **cannot be the same**
- Switch expression data type and case value data type **must match**
- Case value must be a **LITERAL or CONSTANT** (not a variable)
- `default` is **optional**; not all cases need to be handled
- Nested switch statements are possible

**Supported data types:**

- Primitives: `int`, `short`, `byte`, `char`
- Wrapper types: `Integer`, `Short`, `Byte`, `Character`
- `String`
- `enum`

> **Note:** `return` is **not** possible inside a Switch _Statement_ case (only in Switch _Expression_).

---

### 6. Switch Expression (Java 14+)

A modern alternative to the switch statement. Returns a value directly.

**Two ways to use Switch Expression:**

#### Using `case N ->` Label (Arrow syntax — no fall-through)

```java
String day = "";
int val = 1;
String outputVal = switch (val) {
    case 1 -> "One";
    case 2 -> "Two";
    default -> "None";
};
System.out.println(outputVal);  // One
```

- All possible case values **must be handled** when used as an expression
- No fall-through behaviour with arrow syntax
- No `break` needed

#### Using `yield` (for multi-line case blocks)

```java
String outputVal = switch (val) {
    case 1 -> {
        // some code logic here
        yield "One";    // yield returns the value from the block
    }
    case 2 -> {
        // some code logic here
        yield "Two";
    }
    default -> "None";
};
```

- Use `yield` when a case block contains multiple statements and needs to return a value
- `yield` is the switch expression equivalent of `return`

## 3. Iterative (Loop) Statements

### 1. `for` Loop

Best used when the number of iterations is **known in advance**.

**Syntax:**

```java
for (initialisation; condition check; increment/decrement) {
    // statement block
}
```

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
// Output: 1 2 3 4 5
```

**Nested for loops:**

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        System.out.println(i + "," + j);
    }
}
// Output: 1,1  1,2  1,3  2,1  2,2  2,3  3,1  3,2  3,3
```

---

### 2. `while` Loop

Best used when the number of iterations is **not known in advance**. The condition is checked **before** each iteration.

**Syntax:**

```java
// Initialise variable
while (condition check) {
    // block of statements
    // increment/decrement variable
}
```

```java
int val = 1;
while (val <= 5) {
    System.out.println(val);
    val++;
}
// Output: 1 2 3 4 5
```

> **Key difference from do-while:** If the condition is false initially, the while loop body never executes.

---

### 3. `do-while` Loop

Similar to `while`, but the condition is checked **after** each iteration — so the body **always executes at least once**.

**Syntax:**

```java
// Initialise variable
do {
    // block of statements
    // increment/decrement variable
} while (condition check);   // ← semicolon required
```

```java
int val = 1;
do {
    System.out.println(val);
    val++;
} while (val <= 5);
// Output: 1 2 3 4 5
// Even if val started at 10, it would print 10 once before checking
```

---

### 4. `for-each` Loop (Enhanced for)

Designed specifically for iterating over **arrays and collections**. Cleaner syntax, no index management needed.

```java
int[] arr = {1, 2, 3, 4, 5};
for (int val : arr) {
    System.out.println(val);
}
// Output: 1 2 3 4 5
```

## 4. Branching Statements

### 1. `break`

Immediately **exits** the nearest enclosing loop or switch block.

```java
for (int val = 1; val <= 10; val++) {
    if (val == 3) {
        break;    // exits loop when val is 3
    }
    System.out.println(val);
}
// Output: 1  2
```

**`break` in nested loops** — only breaks the **innermost** loop:

```java
for (int outer = 1; outer <= 5; outer++) {
    for (int inner = 1; inner <= 5; inner++) {
        if (inner == 2) {
            break;    // only exits inner loop
        }
        System.out.println(outer + "," + inner);
    }
}
// Output: 1,1  2,1  3,1  4,1  5,1
```

---

### 2. `continue`

**Skips the current iteration** and moves to the next one. The loop itself does NOT exit.

```java
for (int val = 1; val <= 10; val++) {
    if (val == 3) {
        continue;   // skips printing 3, continues to 4
    }
    System.out.println(val);
}
// Output: 1 2 4 5 6 7 8 9 10
```

## 5. Quick-Reference Cheat Sheet

```
Decision Making:
  if           → single condition, runs or skips
  if-else      → two branches (true / false)
  if-else-if   → multiple conditions, first true wins
  nested-if    → if inside if
  switch       → multi-branch on single value (needs break)
  switch expr  → returns a value; use -> or yield; no fall-through

Loops:
  for          → known iteration count; init, condition, update in one line
  while        → unknown count; check BEFORE executing body
  do-while     → unknown count; check AFTER executing body (runs at least once)
  for-each     → iterating arrays/collections; no index needed

Branching:
  break        → exits the nearest loop/switch entirely
  continue     → skips current iteration, continues the loop

Switch rules to remember:
  ✗ Duplicate case values
  ✗ Variable as case value (must be literal/constant)
  ✗ Type mismatch between switch expression and case
  ✓ default is optional
  ✓ Supported types: int, short, byte, char, their wrappers, String, enum
```

## 6. Common Interview Questions

**Q: What is the difference between `while` and `do-while`?**

> In a `while` loop the condition is checked **before** the body executes — if false initially, the body never runs. In a `do-while` loop the condition is checked **after** — the body always executes at least once.

**Q: What happens if you forget `break` in a switch case?**

> Fall-through occurs — execution continues into the next case block without checking its condition, until a `break` or the end of the switch is reached. This can be intentional (e.g., grouping cases) but is usually a bug.

**Q: What is the difference between `break` and `continue`?**

> `break` exits the loop entirely. `continue` skips only the current iteration and moves to the next one — the loop keeps running.

**Q: Does `break` exit all nested loops?**

> No — `break` only exits the **innermost** loop it is inside. To exit an outer loop, you need a labelled break: `outerLoop: for(...) { for(...) { break outerLoop; } }`.

**Q: What is the difference between a Switch Statement and a Switch Expression?**

> A switch _statement_ executes code blocks and requires `break` to prevent fall-through. A switch _expression_ (Java 14+) **returns a value**, uses `->` arrow syntax (no fall-through, no `break` needed), and all possible cases must be covered. Use `yield` inside a block-bodied case to return a value from a switch expression.

**Q: What data types can be used in a switch?**

> `int`, `short`, `byte`, `char`, their wrapper types (`Integer`, `Short`, `Byte`, `Character`), `String`, and `enum`. `long`, `float`, `double`, and `boolean` are NOT supported.

**Q: What is `yield` in Java?**

> `yield` is used inside a Switch Expression block (`case N -> { ... yield value; }`) to return a value from that block. It is the switch expression equivalent of `return`.

**Q: When would you use `for-each` vs a regular `for` loop?**

> Use `for-each` when you only need to read elements — it's cleaner and less error-prone. Use a regular `for` when you need the index, need to modify elements in place, or need to iterate in reverse or with a custom step.
